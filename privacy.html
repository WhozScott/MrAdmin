This Privacy Policy explains what information MrAdmin (the "Bot") accesses when added to a Discord server, and how that information is used. The Bot is operated by [Your Name / Twin Atlas] ("we", "us", "our").

1. Information We Access

The Bot reads limited, non-sensitive server data made available to it through Discord's API in order to function, specifically:

  • Server (guild) member count
  • Basic server metadata needed to operate (e.g. server ID, server name)

The Bot does not read, log, or store message content, and does not collect individual user data such as usernames, user IDs, direct messages, or personal profile information.

2. How Information Is Used

Any data the Bot accesses is used solely to provide its core functionality (such as displaying current member counts) in real time. We do not sell, rent, or share this information with third parties.

3. Data Storage & Retention

The Bot does not maintain a persistent database of user or message data. Where any data is temporarily processed to serve a request (e.g. reading the current member count), it is not stored beyond what's needed to respond and is not retained long-term.

4. Third-Party Services

The Bot operates on top of Discord's platform and is subject to Discord's own Privacy Policy. We do not integrate with additional third-party analytics or advertising services.

5. Children's Privacy

The Bot is not directed at children and does not knowingly collect personal information from anyone under the age required by Discord's Terms of Service.

6. Your Choices

Server administrators can remove the Bot from a server at any time via Discord's server settings, which immediately stops any further data access by the Bot for that server.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Material changes will be reflected by updating the "Last updated" date above.
